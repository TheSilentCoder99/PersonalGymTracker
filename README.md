# 🏋️ Gym Tracker

Un tracker de gimnasio desarrollado para practicar y profundizar mis conocimientos de JavaScript además de obtener como resultado una PWA útil para uno de mis hobbies, que es el levantamiento de pesas.

## Sobre el proyecto

Este proyecto nace principalmente como una forma de aprender construyendo. En lugar de limitarme a seguir tutoriales, quería crear algo útil mientras mejoro mi comprensión de JavaScript y del desarrollo frontend.

El objetivo no es solo tener una aplicación funcional para registrar entrenamientos, sino también profundizar en conceptos como:

* Manipulación del DOM
* Eventos e interacción con el usuario
* Estructuras de datos y objetos
* Local Storage
* Organización modular del código
* Resolución de problemas mediante proyectos reales

## Funcionalidades

* Registrar diferentes entrenamientos
* Guardar ejercicios y series
* Llevar seguimiento de las sesiones
* Almacenar historial de entrenamientos
* Interfaz simple y práctica

## ¿Por qué este proyecto?

Profundizar en JavaScript implica escribir código, equivocarse, refactorizar y aprender a estructurar proyectos reales. Este Gym Tracker forma parte de ese proceso. Además, el que sea un proyecto relacionado con uno de mis intereses mejora mucho la adherencia y el deseo de terminarlo.

## Posibles mejoras futuras

Este proyecto sigue en desarrollo y hay varias funcionalidades que podrían añadirse en el futuro:

* Duplicar entrenamientos completos para reutilizar rutinas habituales.
* Duplicar ejercicios junto con todas sus series.
* Editar entrenamientos, ejercicios y series ya creados.
* Añadir notas personales a entrenamientos o ejercicios.
* Mostrar estadísticas básicas como volumen total, peso movido o progresión de cargas.
* Comparar el rendimiento entre diferentes semanas.
* Crear plantillas de entrenamiento reutilizables.


## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
